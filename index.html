The latest Planar Infinity APK is release.v1.8.apk

Version 1.8, built 2026 Nov 23 Mon 6:00 PM

The new features are:

  • Flatness Chart follows the Run's Standard: ACI F-min (e.g. T60 L60) and other Standards with a Maximum Slope get the Flatness Error (elevation change from step to step) of every Arm, inside each Arm's Maximum Slope e_max band; ASTM E1155 Runs get q (change in slope) with F_f
  • The flatness chart and the elevation chart now really sit side by side on a tablet, scaling to share the row
  • Split Profile Charts: an F-min Run gets a Flatness Error chart beside both the Longitudinal and the Transverse chart
  • The flatness chart's scale is labelled
